# Portfolio rework contract

The owner's latest review rejects the cobalt cabinet, restrained motion, placeholder-like presentation and sparse galleries. The replacement is a product-led experimental portfolio. Existing legal facts and release gates remain intact.

- Homepage: ink/pearl rather than a flat cobalt field; original interactive light-ribbon hero, large typographic composition, real desktop/mobile UI orbit, naturally scrolling project articles and gameplay footage. The former pinned theatre was removed after owner feedback; see `SCROLL_AND_BACKGROUND_RESEARCH.md`.
- Completed products: separate compositions, complete screenshot galleries, platform-accurate captions, interactive full-size viewing and actual recorded media. Never draw imitation application screens or call a desktop viewport an Android release.
- Bookmark: a reading landscape; desktop UI and multiple actual phone screens form a spatial library.
- Sticky Wall: an expansive scrapbook; actual wall, drawing/editor, grid/list/night views take over the page. Tablet/landscape remains labeled accordingly; native PC distribution is not inferred.
- Asset Forge: dark technical gallery; real model inspection/production/library captures, with responsive web UI distinguished from a mobile application.
- Arcane: cinematic gameplay-led introduction, source artwork, combat/boss/shop chapters and a wide image wall.
- Development projects: real captured media where available, clear development states, no artificial release dates or fictional screenshots.
- Motion: real WebGL fragment shader with pointer response; CSS perspective and clip reveals; small scroll-linked transforms inside ordinary-flow project articles; filmstrip movement; magnetic hover; muted on-screen video. Global pause controls CSS, canvas and video. Reduced-motion and WebGL-loss fallback preserve the full readable page.
- Media: source screenshots and existing capture outputs have explicit provenance. Any demonstration content inside genuine app UI is identified as such in gallery context. No fictional testimonials, usage numbers or product results.
- Product explanations: all 22 pages explain their actual purpose and usage/gameplay loop, based on current documentation and relevant implementation in all nine repositories. Verified controls are included where applicable. See `PRODUCT_CONTENT_AUDIT.md`.
- Validation: source/media contract, static export/link checks, browser rendering in normal/reduced motion, shader/context-loss and video/pause behavior, gallery keyboard/lightbox, EN/VI, default/alternate themes and mobile layout.

UI/UX Pro Max returned scroll-triggered storytelling and a portfolio category. Its instant-transition brutalist recommendation and blue accent conflict with the owner's requested motion and rejected blue opening; those details are deliberately not adopted. Frontend engineering guidance supplies semantic controls, actual-product evidence and verification. The later owner brief takes priority over Taste's restrictions on shaders, violet, repeated motion and one uniform visual system.

Primary implementation references inspected: [MDN WebGL shaders](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/Tutorial/Using_shaders_to_apply_color_in_WebGL), [Chrome autoplay policy](https://developer.chrome.com/blog/autoplay). [Lusion](https://lusion.co/) was studied for the relationship between interactive art direction and a project index; no branding, code, copy, images or signature effect is copied.
