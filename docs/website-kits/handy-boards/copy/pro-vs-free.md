# Free and Pro · Miễn phí và Pro

Same table as the app's Pro page (`lib/pro/pro_page.dart`, "Free and Pro"), checked 2026-11-09.
Price: one payment through Google Play, **99,000 đ** in Vietnam and **US$3.89** in the US at launch; Google Play converts it elsewhere and shows the final price before buying. No subscription. Product id `handy_boards_pro`.

| Board templates | 14 | All 30 |
| Covers | 30 | All 60 |

| Planning | Timeline by day/week/month, move to today by hand | + My Work, smart carry-over, repeating cards |

| Export | Plain picture/PDF, CSV, Markdown, ICS, backups | + Poster, printable, report |
| Looking back | Card history | + Board insights, board history |
| Sync, backup, Trash, archive | ✓ | ✓ |
| Ads | None | None |

If Pro ever goes away, nothing you made is deleted; Pro looks fall back to the defaults and come back with Pro.
